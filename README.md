# ImageSlim

사진과 이미지를 **WebP로 한꺼번에 변환해 용량을 크게 줄이는** Windows 프로그램입니다.

## 내려받기

👉 **[최신 버전 내려받기](https://github.com/morethantask-art/ImageSlim/releases/latest)** — `ImageSlim_Setup.exe`를 받아 실행하세요.

- Windows 10 / 11 (64비트)
- .NET 등 따로 설치할 것이 없습니다
- 관리자 권한 없이 설치되고, 시작 메뉴와 바탕화면에 바로가기가 생깁니다
- 새 버전이 나오면 프로그램을 켤 때 상단에 알림이 표시됩니다. 새 설치 파일을 실행하면 설정은 그대로 두고 업데이트됩니다

### "Windows의 PC 보호" 창이 뜨면

코드 서명을 하지 않은 개인 제작 프로그램이라 처음 실행할 때 이 창이 뜰 수 있습니다.
**추가 정보 → 실행**을 누르면 설치됩니다.

## 주요 기능

- JPG · PNG · BMP · TIFF · GIF · HEIC 이미지를 WebP로 일괄 변환 (투명 배경, 움직이는 GIF 유지)
- 품질 조절, 해상도 줄이기 (긴 변 크기 또는 비율)
- 사진 회전, Windows 탐색기와 같은 방식의 선택
- 원본보다 커지는 파일은 저장하지 않음

## 문의 · 제안 · 오류 알리기

프로그램 오른쪽 위 **ⓘ 정보** 버튼(또는 `F1`)에서 메일로 보낼 수 있습니다.
